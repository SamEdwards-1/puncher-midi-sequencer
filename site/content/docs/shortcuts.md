## Editing and files {#editing}

On macOS, use **⌘** in place of **Ctrl**. Editing shortcuts leave text inputs to their normal browser behavior.

| Shortcut | Command |
| --- | --- |
| Ctrl + Z | Undo |
| Ctrl + Shift + Z or Ctrl + Y | Redo |
| Ctrl + S | Save patch |
| Ctrl + Shift + S | Save patch as |
| Ctrl + O | Open patch |
| Ctrl + C | Copy selected step |
| Ctrl + V | Paste onto selected step |
| Ctrl + = / Ctrl + − / Ctrl + 0 | Browser zoom in / out / reset |
| Esc | Close a dialog, menu, or popup |

## Performance and envelopes {#performance}

| Key | Command |
| --- | --- |
| H | Hold |
| Y | Sync selected voice |
| F | Flip |
| T | Transpose |
| B | Toggle Draw / Edit while the envelope graph has focus |
| Alt | Temporarily disable grid snapping while drawing or dragging |

The performance actions stay active while held. With **Latch** on, each press toggles the action instead.
